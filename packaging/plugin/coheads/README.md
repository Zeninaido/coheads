# Coheads プラグイン

Coheads は、チームの「いま有効な決定」（価格、納期、条件、方針など）を、AIが取引先あての見積・提案・メールを書く前に渡すための仕組みです。古い資料に残った価格や、まだ決まっていない事項を、AIが現行として書かないようにします。

## 入っているもの

- スキル「coheads-check」：取引先や案件に関わる仕事の前に、Coheadsで現行の決定を確認する手順。チャット、Cowork、Claude Code で読み込まれます。
- フック：依頼に登録済みの取引先・別名・担当者の名前が出てきたら、AIが読む前に決定を依頼に添えます。Claude Code と Cowork で動きます（チャットでは動きません）。

## 使う前に

データは、Coheads のデスクトップ拡張機能（coheads.mcpb）から取ります。先に Claude Desktop に拡張機能を入れ、資料フォルダを設定してください。拡張機能は Claude Desktop が開いている間、このパソコンの中（127.0.0.1:4319）で動きます。

## 送るデータ

このプラグインは、依頼文をこのパソコンの中の Coheads にだけ送ります。外部のサーバーには何も送りません。
