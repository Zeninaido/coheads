# 評価用の資料フォルダ（架空）

ケースの `data: folder:<名前>` で使う。実行のたびに一時フォルダへ複製するので、ここは書き換わらない。中のフォルダ1つが1案件になる（拡張機能で資料フォルダを選んだときと同じ）。

| 名前 | 中身 |
| --- | --- |
| a-sha-docs | A社の資料5件。決定の記録なし。10万円の提案書と、承認者の名前つきで12万円に改定した承認記録が食い違う |
| a-sha-docs-no-approver | a-sha-docs から、承認記録の「承認者：」の行を消したもの。決定を示す根拠が弱い食い違い |
| a-sha-member-newer | a-sha-approved-130 に、佐藤さんが新しい版（0.9.0）を使っているという記録（`version_used`）を足したもの。版の番号があまりに大きいと、AI が本物か疑う（9.9.9 で見た）。この版が 0.9 に近づいたら上げる |
| a-sha-newer-version | a-sha-approved-130 に、この版では読めない種類の記録（新しい版が書いたもの）を1件足したもの |
| a-sha-approved-130 | a-sha-docs に、月額13万円（11/26から）を候補→承認した記録（`.coheads/events/`）を足したもの。資料のどこにも13万円はない |
| a-sha-newer-doc | a-sha-approved-130 に、11/28 の「価格改定 承認記録（2）」（月額14万円に改定、承認者：佐藤、12/1から）を足したもの。チームでは13万円が現行のまま（S20） |
| a-sha-open-item | a-sha-approved-130 に、11/27 の「保守サポートの検討メモ」（月額2万円の案、採用は保留）を足したもの（S21） |
